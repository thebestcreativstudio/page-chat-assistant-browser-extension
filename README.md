# Page Chat

Chrome-розширення (MV3): чат з ІІ про **поточну вебсторінку**. Без кнопок «відгук / прогалини» — лише діалог.

## Можливості

- Side panel на будь-якій http(s) вкладці
- Автозчитування тексту сторінки (`main` / `article` / `body`, до ~60k символів)
- Якщо виділив текст на сторінці — питання йдуть насамперед про виділення
- **Збережені контексти** (напр. портфоліо): створити в ⚙ → обрати в «Ваш контекст» → підставляється в чат
- OpenRouter free-моделі (каталог підтягується з API, fallback до 3 моделей)

## Встановлення

1. Відкрий `chrome://extensions` → **Режим розробника**
2. **Завантажити розпаковане розширення** → папка `page-chat-assistant`
3. Ключ: [openrouter.ai/keys](https://openrouter.ai/keys)
4. Клік по іконці розширення → side panel → ⚙ встав ключ → Зберегти

На `chrome://` і сторінках розширень контекст недоступний — відкрий звичайний сайт.

## Використання

1. Відкрий будь-яку сторінку
2. Відкрий Page Chat
3. Питай природною мовою (Enter — надіслати, Shift+Enter — новий рядок)
4. «Оновити контекст сторінки» — якщо DOM змінився після SPA-навігації

### Збережений контекст (портфоліо тощо)

1. ⚙ → **Створити контекст** → назва, обов’язковий текст, опційно кілька `.txt` / `.md`
2. **Ваш контекст** → у select обери потрібний (за замовчуванням «немає»)
3. **Видалити обраний** — прибрати зі списку
4. У хедері з’явиться рядок «Збережений контекст: …» — він іде в кожен запит до ІІ разом зі сторінкою

## Структура

```
manifest.json
src/background/service-worker.js
src/content/page.js          # знімок тексту сторінки
src/sidepanel/               # чат UI
src/lib/openrouter.js        # chat + fallback
src/lib/models.js            # live :free каталог
```

## Примітка

Це окремий проєкт від `djinni-ai-assistant` (той — під відгуки на Djinni).
